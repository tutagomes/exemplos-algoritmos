## Exemplos de Algoritmos

Repositório público com pequenos exercícios lúdicos sobre programação.

Abra o arquivo [index.html](index.html) para acessar as páginas do projeto:

- [Desenho por Sequências](pixel-grid.html): monta imagens com sequências de pixels em branco e preto.
- [Robô no Labirinto](robo-labirinto.html): guia o robô até a meta usando comandos de movimento.
- [Onde os apps guardam as coisas](gavetas.html): compara a memória temporária (a lousa) com o armazenamento permanente (o caderno) e mostra como os apps guardam informações em gavetas.
- [Objetos dentro do armário](objetos-gavetas.html): continuação da trilha anterior, mostra como descobrir os campos de um objeto e guardar várias informações juntas numa mesma gaveta.
